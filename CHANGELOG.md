# Changelog

All notable changes to Open Device Toolkit are documented here.

## Unreleased

### Added
- Initial project roadmap.
- Initial architecture and design principles.
- AI/developer handoff documentation.
- Safety boundary for read-only inspection versus persistent writes.
- Robust ADB executable discovery across the ODT Tools workspace and Windows PATH/PATHEXT.
- Structured JSON Lines application logging under the ODT Logs workspace.
- ADB path and inspection lifecycle evidence in the reconnaissance UI.

### Planned
- .NET 8 Windows application shell.
- ADB discovery and Android device inspection.
- Basic Windows/tool environment diagnostics.
- Automated tests.
- CI build verification.

## Versioning

Until the first stable release, version numbers may use `0.x.y` to indicate alpha development. Milestone names in `ROADMAP.md` describe capability maturity rather than guarantees of release dates.
